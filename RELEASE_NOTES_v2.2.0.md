# LeadMailer v2.2.0

## 🚀 Novedades principales

- Nueva pestaña **Alumnos** con agrupación por curso.
- Los leads con etiqueta **Confirmado** aparecen automáticamente como alumnos y se mantienen sincronizados.
- Alta manual de alumnos con los mismos campos del lead.
- Edición y eliminación de alumnos manuales.

## 🛠️ Instalador y versión

- Versión de app actualizada a `2.2.0`.
- Script de build del instalador actualizado para usar `2.2.0` por defecto.
- Script de Inno Setup actualizado a `2.2.0`.

## ✅ Compatibilidad

- Proyecto sobre `.NET 8` (WPF).
