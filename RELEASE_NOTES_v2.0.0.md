# LeadMailer v2.0.0

## 🚀 Novedades principales

- Interfaz optimizada para pantallas pequeñas (portátiles de 13").
- Panel lateral redimensionable con `GridSplitter`.
- Mejor uso del espacio en tablas de `Leads` y `Leads antiguos`.
- Botón para mostrar/ocultar filtros (`🧭 Filtros`) en vistas de leads.
- Reorganización responsive de botones y filtros (saltan a nuevas filas cuando no hay ancho suficiente).
- Nuevo botón en `Cursos`: `🧹 Borrar sin configurar` para eliminar cursos no configurados en lote.
- Actualización del proveedor Gemini: modelo preferido `Gemini 3 Flash Preview`.

## 🛠️ Instalador y versión

- Versión de app actualizada a `2.0.0`.
- Script de build del instalador actualizado para usar `2.0.0` por defecto.
- Script de Inno Setup actualizado a `2.0.0`.
- Tag de versión publicado: `v2.0.0`.

## ✅ Compatibilidad

- Proyecto sobre `.NET 8` (WPF).
